# GripWise promo video

A 30-second motion graphics pitch for GripWise (1920 × 1080, 30 fps), built with [Remotion](https://www.remotion.dev/). It uses real screens from the app and an original soundtrack generated by `scripts/music.py`, so there are no stock or licensing issues.

| Time | Scene |
| --- | --- |
| 0–4 s | Hook: "Numb fingers at 3 AM?" / "Tingling every time you type?" |
| 4–6 s | "Hand exercises help. If you actually do them." |
| 6–10 s | Logo reveal |
| 10–14 s | Guided sessions |
| 14–18 s | Adapts to pain, three-phase programme |
| 18–22 s | Progress tracking |
| 22–26 s | Private by design, CSV export |
| 26–30 s | Download call to action |

At 120 BPM one bar is two seconds, and every scene starts on a bar line so the cuts land on the music (see `src/Promo.tsx`).

## Render

Requires Node.js 20+ and Python 3 with NumPy (for the soundtrack).

```bash
cd promo
npm install
npm run studio   # preview and edit in the browser
npm run render   # writes out/gripwise-promo.mp4
npm run still    # writes out/poster.png, a thumbnail frame
```

Remotion downloads its own headless Chrome the first time. To use one you already have, set `REMOTION_BROWSER_EXECUTABLE` to its path.

## Editing

- **Text:** the scenes in `src/scenes/` (`Intro.tsx`, `Features.tsx`, `Outro.tsx`).
- **Timing:** the `scenes` list in `src/Promo.tsx`, in bars. Change `scripts/music.py` to match if you move a cut.
- **Colours:** `src/theme.ts`, which matches the app.
- **Screens:** `public/screens/` are 1170 × 2532 captures of GripWise 2.0.0 running with four weeks of demo data.

Plus Jakarta Sans is used under the SIL Open Font License (`public/fonts/OFL.txt`).
